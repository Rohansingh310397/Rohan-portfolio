# Rohan Kumar Singh — Portfolio

A responsive, one-page portfolio for **Creative Operations & AI Automation Specialist**.

## What's included
- Seven sections: Home, About, Selected Work, AI Playground, Automation Lab, Experience & Skills, Contact.
- Original screenshots and creatives supplied for the portfolio.
- Interactive 3D scenes built with Three.js: abstract particle sculpture on Home, orbital portrait accents on About, network sphere in AI Playground, workflow nodes in Automation Lab, data bars in Experience, and a glass-orbit contact sculpture.
- Responsive mobile layout, reduced-motion support, and a mobile navigation menu.
- Download Resume buttons linked to `assets/Rohan-Kumar-Singh-Resume.pdf`.

## Publish on GitHub Pages
1. Download and extract this ZIP.
2. Upload the **contents** of this folder to the root of your existing `rohan-portfolio` repository (replace the old `index.html`, `style.css`, `script.js`, and `assets` folder).
3. Keep the `.github/workflows/pages.yml` file in the repository. Note: the folder name starts with a dot.
4. In GitHub, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source if it is not already selected.
5. Wait for the Actions workflow to finish, then refresh your Pages website.

## Notes
- The 3D scenes use Three.js from a public CDN. An internet connection is needed for those scenes to load; the rest of the portfolio content remains available without them.
- The page uses the user's real supplied screenshots and profile photo. Project metrics are not invented.
- Experience is displayed as **5+ years**, based on the supplied employment dates: October 2021 to present (November 2026).
- Review the resume PDF before publishing if you want a different CV version linked.
