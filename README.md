# Rohan Kumar Singh — 3D Creative Operations Portfolio

A responsive, static portfolio for GitHub Pages. The site keeps the original seven sections and uses the supplied profile photo, project screenshots, dashboards and resume.

## What's included
- `index.html` — Home, About, Selected Work, AI Playground, Automation Lab, Experience & Skills, Contact
- `style.css` — responsive ivory, ink and deep-olive design; portrait framing; floating visual details
- `script.js` — interactive Three.js scenes for the hero particle sculpture, AI object, automation workflow, data bars and contact environment
- `assets/` — original supplied photographs, project screenshots, dashboards and resume
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow

## 3D experience
The site uses Three.js (loaded from a public CDN) for rotating 3D geometry, particle fields, orbital rings, workflow nodes and pointer-responsive movement. The Home section places the original profile photograph in front of the rotating particle/orbit sculpture. The same real photograph is retained in About and Experience, with image framing adjusted to keep the face visible.

A network connection is required for the Three.js CDN and Google Fonts. The rest of the site is static HTML/CSS/JavaScript and can be hosted free on GitHub Pages.

## Publish on GitHub Pages
1. Extract this ZIP on your computer.
2. Open the repository's `main` branch.
3. Choose **Add file → Upload files**.
4. Upload the *contents* of this extracted folder (including the hidden `.github` folder), not the ZIP itself.
5. Commit directly to `main`.
6. Open **Settings → Pages** and choose **Deploy from a branch**, branch `main`, folder `/ (root)` if it is not already configured.

## Before sharing
Check the site on desktop and mobile, and verify all contact details and experience dates. Project screenshots are original supplied materials; descriptions avoid claiming automatic job applications or automatic LinkedIn sending.
